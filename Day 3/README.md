# 🏦 Bank Simulator API - Python Edition

A comprehensive banking system API built with Flask and OOP principles in Python.

## 📚 Features

- **User Management**: Registration, login, profile management
- **Account Management**: Create, view, freeze, close accounts  
- **Transactions**: Deposit, withdraw, transfer between accounts
- **Security**: JWT authentication with refresh tokens
- **OOP Design**: Clean, maintainable object-oriented code
- **Error Handling**: Comprehensive error responses

## 🚀 Quick Start

### Installation

```bash
# Clone the repository
git clone <repository-url>
cd bank-simulator-python

# Install dependencies
pip install -r requirements.txt

# Create .env file with your configuration
cp .env.example .env
